# v4 最小修改说明

针对 v3 稳定性批次反复出现的三类问题，保留 v3 文件及默认 DESIGN.md。v4 由本目录 prompt.txt 单独提供给现有 backend，未修改解析器、校验器、输出结构或历史文件。

- 第2条：先固定仅由旧记忆产生的 raw，允许句段，不为语法完整从上下文补主体。增加一个完全自拟的杯子偏好例子；上下文多余的书桌细节不写入事实。依据是此前5/7例 raw 补入用户主体；这不等于5例虚构身份。
- 第11条：每项 supports 限于单条 quote 的局部支持，区分直接表达、相容、未证实，说明角色元数据的边界。不把名称使用当身份验证，不把助手问句或一般回应当用户承诺。增加一个自拟了解绘画意愿的反例。依据是此前2/7例支持范围扩写。
- 第12条：具体区分语义主体、原始说话人、真实身份等待确认对象；正文和 supports 不得同时声称同一未定项已验证。依据是此前2/7例确定程度冲突。

三类计数有重叠，属于 AI 初审，待人工确认。未针对仅出现一次的效果扩写追加案例答案；原有最小上下文规则保持不变。未增加最低拆分条数、特定人物或真实案例答案。

JSON 结构、必需 memory 引文、逐字匹配、事实编号及校验规则均保持不变。自拟例仅用现有 MockBackend 本地校验，通过不代表语义已最终确认。v4 在看到本轮输出前冻结，之后不会自动调整。
