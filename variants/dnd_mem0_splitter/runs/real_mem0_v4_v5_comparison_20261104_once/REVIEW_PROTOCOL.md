# v4/v5 语义初审协议

所有语义结论标“初步判断，待人工确认”。逐条审查两个版本的事实及每项 supports，程序通过仅证明结构与逐字引文。

检查 raw 来源边界、补充必要性、否定/时间/条件/情态、关系正文保留、覆盖及 pending 一致性。按独立可变谓词观察粒度，不以条数增加自动计改进。连接在 quote/pending 出现不能替代正文保留。原文语法多解则列作用范围未决，不选定因果或时间解释。

每条 quote 分开评估 directly_supported / partially_supported / overreach / uncertain；不能借另一个来源把局部引文写成直接证实。明确区分旧记忆、用户自述和助手回述。来源强度差异记录未决，不纠正模型旧命题。

历史 v4 原始 pending 和本轮 v5 原始 pending 均原样展示；初审发现另列。失败候选保留，不修补、不改标。全部五例是已见定向回归案例，单次差异不等于稳定性或泛化。
