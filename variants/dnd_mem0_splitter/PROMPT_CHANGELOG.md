### 具体调整

| 已观察的问题 | 新版通用约束 |
| --- | --- |
| 人名保留但关系遗漏 | 事实文本覆盖名单、身份和群体关系；引文保留不能替代事实覆盖；不将群体身份分配给每个人 |
| raw 借助上下文明确主语或受益人 | raw 仅可恢复旧记忆内部共享成分；缺少身份时可保留省略表达并标记待确认 |
| 有来源的评价、效果和括号解释进入补充版本 | 默认复制 raw；逐项用删除后是否仍可无歧义理解检查补充必要性；禁止一般佐证与来源对照评述 |
| 动作或态度对应的特征改变 | 固定谁对什么、因为什么的关系；来源不同不能替换旧记忆的关系，差异记入待确认 |
| 直接理由改成主观推测 | 保持原文断言及已有态度范围，不额外加入认为、感到、似乎；来源不确定单列待确认 |
| supports 超出 quote | 仅说明当前引文直接支持的部分，不推导未明确表达的场景、功能、原因、时间或来源归属 |
| 助手回述被当作用户原话 | 区分记忆记载、直接自述和他人回述；speaker 仅标记来源说话者，不能自动决定所有旧命题的主语 |

新版没有加入这三条记忆的人名、动物名称、真实 ID、原文片段、期望拆分事实或人工标准答案。约束由既有失败模式抽象而来，JSON 结构和原有通用条件句示例保持一致。
