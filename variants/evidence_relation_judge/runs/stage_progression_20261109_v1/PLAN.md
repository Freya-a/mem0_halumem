# 有来源的阶段历史化候选计划

目标：对现有完整 v4/v2 接口附加可关闭的独立阶段抽取与候选计划；只读、不写入、不推断具体事件日期，旧版代码和产物可重放。

1. 追踪目标 7 原始模型输入、生成原文、解析与校验；区分模型原始判断、输入缺口与传递层。
2. 新增 v3 关系提示：一般性区分同一事项的进行/完成/仍计划与新增兼容体验；原 v2 文件保持不变。实际模型行为单独记录，不将提示约束当成成功证明。
3. 增加阶段结构化抽取：引用旧记忆及真实新来源、区分阶段/同一事项/时序依据、对象/条件及受保护范围；模型结论均为候选，引用只验证字面。旧片段必须位于本事实引文、全记忆唯一；不明/计划/不同事项/否定/冲突则待确认，不自动形成历史化。输出位置、旧新阶段、保护、引文、相对时间和未知精确时间。
4. FactTrack 按先边界、相交再插入的思路组织纯候选计划；只对真实源区间调用旧版已有原排序/谓词，不生成无来源数值时序。记载实际上调用的作者代码与新增代码。
5. 调试 7、10 及防越界 8、14、24；固定代码/提示后再用其他有人工确认的 9、17、19 检查，两个组分别报告。若候选提取或上游失败保留错误，不用预期值填模型结果。
6. 离线测试及逐案只读运行，保留旧版和新版输出、模型调用数和 NLI 状态；不运行完整开发子集或写入 Mem0。
