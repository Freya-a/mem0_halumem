# 旧记忆拆分器实施计划

范围：仅创建此目录；不读取旧拆分器，不修改作者仓库、基线或向量库。固定模型 qwen-plus-2025-12-01，最多五次，一次失败停止。

1. 改造 SimpleMem 的 MemoryEntry、MemoryBuilder 提示词、响应解析；保留许可证与逐项来源说明。
2. 先用手写响应测试正常、多段引文、错误引文、重复定位、上下文、缺失字段、时间与指代不明、非法 JSON；验证失败再实现。
3. 以 HaluMem 的 original_memories 选 5 条，记录精确索引；不将对应更新事实交给拆分器。每例一次调用、零自动重试、持续保存记录。
4. 汇总程序校验与逐例语义检查，区分自动检查、研究者初评和待人工验收；验证结果与作者工作区。
