# 模块一：真实模型范围判断小规模检查

## 结论

2026-11-05 09:41:42–09:42:46（Asia/Shanghai），检查 3 个开发子集案例，共 **9 次实际 SDK 请求**：3 次 v4 拆分、3 次逐事实判断、3 次新增候选提取；0 次自动重试，0 次请求或解析失败。上限 10 次，剩余 1 次不足以为一个新案例完成至少 1 次拆分和 1 次判断。3 个选中案例的拆分与事实判断均完成。

**暂不适合直接扩大到开发子集。** 晋升案例识别了新旧职位的先后关系，却未把具体职称与雇主分别列为修改和保护范围；模拟跳伞案例把一次模拟体验作为直接否定整个极限运动顾虑的依据，修改范围过大，还把陈述日期与体验日期混淆。职业历史案例正确保护了未涉及的旧事实，但新增候选的理由出现无依据的“创办公司”。需要先解决复合事实的局部范围、模拟与真实活动的区分、相对时间及候选理由溯源，再做人工复核的小样本检查。3 例、单次采样不是效果估计。

本报告的“正确／遗漏／越界”是本次对照既有用户确认事实边界所做的分析，**不是用户已经确认的本轮模型评分**。用户原确认的是数据与允许范围，不是本轮模型输出或实际 Mem0 操作结果。三个目标的原始确认层为 LLM 辅助、用户确认；尚待确认的细节和无法判断事项以下分列，不当作金标准。

## 每案产物和运行方式

每案目录均有 `source_provenance.json`、`model_input.json`、`split_result.json`、`judge_result.json`、`candidate_stage.json`。模型候选修改计划在 `judge_result.json` 的 `facts[].components`；其中包含事实及旧／新证据引用和理由。新增候选在独立 `candidate_stage.json`。完整模型 system prompt、实际输入、原始模型 **content**、解析 JSON、finish reason 和用量保存在 [calls/](calls/) 下按编号排列的各目录；原始 content 不是完整 HTTP 响应包。所有 content 可解析，所有 finish reason 为 `stop`。

为优先保证事实范围请求，调用 `judge` 时故意把新增候选阶段推迟：因此各 `judge_result.json` 的 `new_candidates.status=failed`、`error_type=CandidateStageDeferred` 是**显式未执行标记，不是模型调用失败**。有剩余额度后，各案例在原模块相同 `CANDIDATE_PROMPT` 和 `_validate_candidates` 下各调用一次，结果保存在相应的 `candidate_stage.json`；没有覆盖原 `judge_result.json`。本次没有拆分、判断或独立候选的处理错误；若把推迟标记直接当作模型错误会误读结果。

- 配置：[run_config.json](run_config.json)：`qwen-plus`，端点主机 `dashscope.aliyuncs.com`，generation 参数未显式指定、由服务端默认，timeout 180 秒；SDK `max_retries=0`、禁用 HTTP redirect。配置变量及来源已记录，未保存密钥。
- 提示词：[v4 prompt](../../../dnd_mem0_splitter/prompt_versions/v4_boundaries_20261104/prompt.txt) 的运行时绝对路径见配置；SHA-256 `d9cc40259ac447e09cad93b775d7f0ff67fc9bb42443e18264b75f39b37067f3`。
- 调用计数：[call_journal.jsonl](call_journal.jsonl) 在请求前持久预留编号，[run_summary.json](run_summary.json) 汇总 9 次调用、0 次未明调用；每次保留请求和响应。运行器只允许创建一次启动标记，单次总额硬上限 10。
- 只将前快照旧记忆、旧的用户原始上下文和新用户原话传入；人工核验、预期答案及评估字段只用于选案／报告。拆分模型自己生成的 `pending_confirmations` 属于拆分结果，会随该事实交给判断器，并非人工标签。没有读写线上 Mem0、修改原始数据或改写既有运行结果。
- [verify_run.py](verify_run.py) 离线复验来源哈希、请求数、v4 提示词、逐字引文与模式；[test_driver.py](test_driver.py) 离线验证预算和输入隔离。自动验证不能判断语义是否正确；本报告的逐案对照是分析意见，待用户复核。
