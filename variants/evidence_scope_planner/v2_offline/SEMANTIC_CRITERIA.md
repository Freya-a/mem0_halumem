# 独立人工语义核对标准

审核对象和接口诊断分开：逐记录检查三版模型保存的每条 parsed record；另外逐项检查新旧规划器的 modify、preserve、uncertain、add 和位置保护。`SEMANTIC_REVIEW.json` 的陈述是研究者独立依据原文和来源上下文人工核对，不从程序输出或人工期望机械生成，也非用户确认的金标准。先检查证据的字面和来源，再判断其是否支持涉及的主体、属性、值、条件、时间、模态与关系。旧文内容和新证据应区分为历史陈述、正在发生、变化、补充与计划，不能由“有交集”直接推出变化，也不能由未提及推出否定或一致。

每条**原模型记录**的分母是五案各版 parsed records 的总条数；每条只能标 `supported`（关系和范围由引文完整支持）、`partial_or_unknown`（有部分支持或无法判定）、`unsupported`（重要关系与证据冲突或超出证据）。缺引文、来源错误、缺维度、相对时间、同主体和语义支持均注明依据，不能仅因 schema failed 推断语义错误，也不能仅因引文命中推断语义正确。审查对象是该条实际声明，不覆盖未输出内容。

每条**规划器动作**单独人工审查。modify 是否有证据支持在对应范围改变、能否先后定位及是否保护旧事实；preserve 是否保留的事实和时间状态有依据；add 是否确有新事实和正确模态；uncertain 判断待确认是否适当/过度、是否遗漏明确的不确定点。editable_spans 和 protected_facts 在逐项报告时校验来源、位置和同句事实，不能仅凭 edit 存在判通过。计划/意图不能升级为已完成，语义不足的待确认可能是正确行为。逐输出的评语应由人工针对具体输出填写；没有人工核对的条目必须明确标为 `not_reviewed`，不能根据程序算出的字段自动判定正确。模型未输出的必要事实要另列为覆盖遗漏，不能因分母只有输出条目而隐去。

客观统计分母分别为：原始 parsed 记录数；每侧原始 quote 数（缺失/多条不默认为一条）；明确 source_id 引文在对应源文本中唯一匹配数、字符串引文在可关联源中唯一消歧数；投影后保留/未解析的原始引文数；每类别产生的规划器输出数。各指标独立统计，不是准确率或语义评分。源文本及快照来源见 SOURCES.md，完整计划以对应 results JSON 为准。人工输入、人工预期、人工语义审核和模型输出互不混用。
