# v3 离线错误归因与范围修复

仅使用既有五次响应和旧版代码，保留原结果。旧规划器 `unconditional` 表示明确无条件约束，但不包含可枚举的全集；`unknown` 表示连适用范围都不知道；`finite` 表示给定维度上的完整有限组合。禁止把条件解析失败后留下的中间结果当成空交集。

同维有限集合按完整组合求交/差；无限定旧范围与有限新范围的有限交集可以在具备独立语义授权、来源及相对时间依据时操作，但域外剩余不能枚举，只能明确待确认，不能构造保留组合；缺范围或维度不一致时不猜交集和剩余。不同事实和不同受影响组合分开处理，保留旧有来源、模态、时间和独立语义门槛。

公平对照：用 frozen-at-call 对齐适配器生成同一输入，分别给 v2 与 v3；另外用保护后的适配输入分别给 v2 与 v3。确认输入哈希相同，并复核 v2 首次/保护后计划与已保存结果一致。五案的人工预期和事后审查仅用在报告，不进入模型投影。另用独立构造的通用输入模拟明确、独立的语义审核，验证新增与修改路径；未经审核的同一输入不授权动作。
