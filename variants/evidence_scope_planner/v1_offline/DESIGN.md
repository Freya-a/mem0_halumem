# 离线影响范围规划器设计与实施计划

目标：对一条旧记忆和选定新证据生成可审查的修改、保留、待确认和独立新增计划，不调用模型或写入记忆。仅处理上游明确表达的主体、属性、值、关系和条件，缺项保持未知。证据可追溯到原文的唯一位置。

方案：采用适配层与纯函数规划器分离。适配器只映射已保存字段并记录损失；人工核对输入独立存储。范围运算针对有限离散条件的笛卡尔组合，明确无条件和未知分开。另一种直接从自然语言推断范围的方案不符合离线、禁止猜测的要求；把每个维度分别求差会丢失有效组合。

实施与验证：
1. 审计三版对齐、拆分结果和原始来源，保留无法确认的事项。
2. 先测试再实现纯函数：引文和来源验证、范围组合差、同值不修改、计划、冲突和未知保守处理。
3. 实现模型结果适配器及独立的人工输入和人工预期；原始模型输出不得用人工判断补齐。
4. 同一规划器离线回放两组五案，保存机器结果和逐案报告；用二维四组合验证组合差。
5. 运行离线测试并审查报告、结果及未覆盖的限制。
