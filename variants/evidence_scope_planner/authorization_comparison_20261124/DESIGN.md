# 离线授权方式对照设计

同一保存的 v4 原始响应和 v3 规划器，对比 A 独立语义授权门槛、B 模型可定位候选和 C 既有人工核对输入。所有动作均为研究候选，不接入写入层。A/B 使用同一 frozen v4 适配数据，A 的模型语义授权保持 unknown；B 仅对逐字来源和关联单元可核验的模型记录设置 v3 兼容的候选标记，不意味着独立审核。无效来源、字段、模态、条件、时序及其他 v3 门槛不得删除。B 可将一条 change 的新侧作为独立新增候选：只复制模型已有的新侧内容及已引用来源，排除仅针对旧关系的时序/旧引文错误；独立候选与原 change 是不同判断，不能以新增正确支持修改。候选主张仍可能超出证据，报告逐项核对。

C 直接读取 v2_offline 已有人工对齐 fixture，由同一 v3 planner 计算；人工输入不是模型输出，不从人工预期填补 A/B。三组计划及其每个输出均在执行后以来源和内容哈希绑定独立审核，明确正确、错误、部分支持、待复核；逐案例出有依据但没有行动的事实。按输出个数统计仅用于诊断，不视为准确率。读旧文件并核对 hash，不修改旧文件/结果，不调用模型。
