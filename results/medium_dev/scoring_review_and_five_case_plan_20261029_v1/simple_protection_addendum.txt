Additional memory preservation guidance:
When updating or deleting, preserve independently supported details that are not contradicted by the new facts. If only one attribute changes, retain unrelated attributes and relevant historical context. When a fact has clearly changed, represent the new state and distinguish the earlier state as historical when appropriate; do not assume an exact date. Do not invent facts. If an old detail is not contradicted but cannot be safely merged, retain it separately rather than discard it. Apply the existing ADD, UPDATE, DELETE, and NONE operations and existing ID and JSON rules.
