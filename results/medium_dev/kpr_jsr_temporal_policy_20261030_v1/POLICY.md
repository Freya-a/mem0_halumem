# 用户确认的统计口径

以下为用户本轮确认的口径，记录在独立目录，不修改此前复核或冻结审核。

1. 历史事实的时间表达允许结合同一用户、相应会话截点内的相关记忆和上下文判断，不要求每条旧句都明确写“过去”。若仍无法判断时间归属，记为待判断；若明确将过时状态作为当前事实表达，记录为时间表达错误。保留证据，不因缺少时间词自动判损伤或自动判保留。
2. 案例 C 的“曾在 Blockchain Tech 担任高级开发人员”在 KPR 主统计中作为一个岗位事实，雇主和高级职级作为两个损伤细节记录。其他岗位类事实使用同样粒度；无法一致处理的情况单列。细节统计不与主 KPR 分母混加。
3. 既有 110/113 和 0/15 在剩余候选及人工判断完成前仍属暂定；目标单位和会话单位的 JSR 分开报告，不相加。
