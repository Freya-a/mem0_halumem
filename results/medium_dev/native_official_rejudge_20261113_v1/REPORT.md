## 来源、配置和合并

评分模型沿用 `qwen-plus`、temperature 0、max tokens 16384、timeout 180、相同官方文件及 Python 3.10.20 / OpenAI SDK 2.44.0；API 实际返回的模型名同为 `qwen-plus`，它是服务别名，不能证明与原运行权重完全相同。官方评分函数每项调用一次；SDK 仍沿用原来的最多两次内部连接重试，服务端实际尝试数不可由本地调用次数推断。[run_config.json](run_config.json) 保存配置和输入/代码哈希，密钥未保存。

只将三条有效补评替换进原始逐项结果的副本，再直接调用官方 `aggregate_eval_results`，生成 [merged_official_scores.json](merged_official_scores.json)。4 条无效项保留原状，其他原有效条目均未改变；逐项复核结果见 [verification.json](verification.json)。本次基于同一 3 用户、28 会话开发子集，不作为完整 HaluMem-Medium 成绩。
