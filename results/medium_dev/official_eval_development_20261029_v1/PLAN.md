# 开发子集评测执行计划

目标：基于审计确定的 56 更新候选和 75 道 QA，按各自会话后快照完成官方分类流程并保留逐项证据。小测结果原样导入，不重复计费。所有文件在本目录，原始材料只读。

1. 校验数据、清单、会话顺序及快照哈希；测试空检索、非法评分、调用中断、prompt 数据边界和分母。
2. 用 SQLite 将每条各阶段的请求、响应、usage、错误原子持久化；启动前记录状态，结束后保存，无自动重试；未确定完成的在途调用标为未知且不重复调用。独立文件锁阻止并发续跑，已完成阶段不重跑。
3. 从快照在内存重建 Qdrant，逐条使用本地同型 embedding 搜索；QA 按官方 prompt 仅输入问题与检索内容；官方提示词单独评分。并发仅跨题，单题各阶段顺序执行。
4. 逐项导出、汇总 all/valid 分母、遗漏/错误/待复核、调用量及使用量；人工保护诊断引用原审查且独立报告。

固定限制：不输入原会话；不改原生库、备份、原数据、审核、小测；不得把空检索或失败自动定分；不得输出密钥。复用 pilot 五次调用时显式标注来源及统计归属。
